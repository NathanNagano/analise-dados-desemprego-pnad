# 📊 Análise de Dados Públicos – Desemprego no Brasil

Este projeto realiza uma análise exploratória da taxa de desemprego no Brasil,
utilizando dados públicos da PNAD Contínua, disponibilizados pelo IBGE.

## 🎯 Objetivo
Analisar a evolução trimestral da taxa de desemprego e identificar tendências
no mercado de trabalho brasileiro por meio de dados reais.

## 📁 Dataset
- Fonte: IBGE – PNAD Contínua
- Periodicidade: Trimestral
- Formato: CSV

### Colunas:
- `periodo`: trimestre de referência
- `valor`: taxa de desemprego (%)

## 🛠️ Tecnologias Utilizadas
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- CSV

## 📈 Análises Realizadas
- Estatísticas descritivas da taxa de desemprego
- Identificação dos maiores e menores índices
- Visualização da evolução temporal
- Interpretação de tendências econômicas

## 🧠 Principais Insights
- A taxa de desemprego apresentou queda significativa entre 2023 e 2025.
- O menor índice da série ocorre em 2025.
- Dados trimestrais permitem observar variações sazonais.

## ▶️ Como Executar
1. Clone o repositório
2. Instale as dependências:
   pip install pandas matplotlib
3. Execute o notebook 'analise_desemprego_brasil.ipynb'
